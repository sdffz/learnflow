## 覆盖范围

后端覆盖：

- 无密钥 Mock 模式。

- OpenAI-compatible 模型协议。
- 课程 CRUD、文件上传、快速笔记、知识片段和全文搜索。
- PDF/DOCX/PPTX/Markdown/TXT 提取与图片 OCR 降级。
- 示例资料幂等导入、资料级联删除和文件清理。
- 资源运行读取所选个人课程知识片段并写入来源元数据。
- 匿名访问 401、跨站写请求 403、登录限流 429。
- scrypt 密码哈希、会话撤销、用户/工作空间隔离和首用户迁移。
- 伪装图片上传拒绝、工作空间配额和文件内容 MIME 校验。
- readiness、请求 ID、审计日志和 SQLite WAL。
- 学习通二维码状态、加密会话、切换工作空间隔离、课程预览和文件夹映射。
- 学习通后台下载、视频链接笔记、部分失败重试、临时文件清理和重启恢复。
- ZIP 路径穿越、符号链接、加密成员、嵌套压缩包、成员上限和解压体积。
- 学习通关闭时 ZIP 导入、断线停止在线下载、二维码会话清理和目录请求预算。

## 已知警告与限制

- Playwright 运行时 Node 会输出 `NO_COLOR`/`FORCE_COLOR` 环境提示，不影响测试结果。
- Vitest 在 Node.js 25 上会输出 `localstorage-file` 环境警告，不影响测试结果。
- 真实模型端点未提供密钥，因此未验证真实模型的质量、费用和延迟。
- Playwright 自动化在桌面 Chrome 执行；另使用 390 × 844 视口完成个人知识首页和采集面板截图检查，尚未做真实手机验收。
- 图片 OCR 的实际识别质量依赖服务器安装 Tesseract 与中文语言包；未安装时系统明确降级为仅保存图片。
- 当前为 SQLite 单节点版本。PostgreSQL、邮箱验证、密码重置和独立任务队列属于下一阶段。
- 公网注册开放；第一个注册用户会成为迁移前默认工作空间的所有者。
- 学习通适配器依赖上游页面结构；真实学习通账号只用于部署后的本人扫码验收，不进入 CI。
