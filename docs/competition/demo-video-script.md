# 7 分钟演示视频脚本

## 0:00—0:35 问题

画面：首页。

旁白：不同学生的基础、目标和偏好差异很大，但课程资源通常是统一的。知序 LearnFlow 希望让画像真正参与资源、路径、辅导和评估。

## 0:35—1:25 对话式画像

操作：

1. 选择“概念入门型”。
2. 输入“我零基础，想完成项目，喜欢视频，每周学6小时。”
3. 展示八维画像、证据和置信度。

旁白：系统没有要求填写长表单，而是从自然语言提取特征，并保留每条画像的来源。

## 1:25—3:05 多智能体资源生成

操作：

1. 进入资源工作室，选择“神经网络”。
2. 启动生成，观察 Agent 时间线和 SSE 进度。
3. 依次展示讲解、导图、题目、代码、课件和动画。

旁白：编排、课程分析、资源规划、六个生成角色和质检角色产生可持久化事件。单类资源失败不会阻断其他结果。

## 3:05—3:50 个性化差异

操作：

1. 对比入门型的补全式代码实验。
2. 切换考试型或展示其预生成结果。
3. 指出难度、媒介和推荐理由的差异。

旁白：个性化不是换一段欢迎语，而是同一知识点下资源难度、呈现方式和学习顺序发生变化。

## 3:50—4:35 学习路径

操作：进入学习路径，展示当前节点、前置依赖和推荐资源。

旁白：路径根据目标和薄弱点重排，神经网络薄弱时提前补强，并为每个节点解释推荐原因。

## 4:35—5:25 有依据辅导

操作：

1. 提问“什么是监督学习？”
2. 展示答案与课程来源。
3. 提问知识库外问题，展示拒答。

旁白：系统先去除问题框架并修正否定短语边界，再检索证据。没有依据时拒绝编造，提示注入也不会绕过约束。

## 5:25—6:15 学习评估

操作：

1. 完成五道题。
2. 提交并展示得分、知识点掌握度和建议。

旁白：后端评分后把掌握度写回画像，形成下一次资源推荐和路径调整的依据。

## 6:15—6:45 技术与边界

画面：架构图。

旁白：FastAPI、React、SQLite 和可重放 SSE 构成完整链路；默认 Mock 模式可离线演示，也可接入兼容模型接口。

## 6:45—7:00 总结

旁白：知序 LearnFlow 把个性化学习做成可解释、可验证、可继续扩展的闭环。

## 录制检查

- 使用 1920×1080 或更高分辨率。
- 隐藏 API Key、浏览器书签和无关通知。
- 全程不超过 7 分钟。
- 配音与画面操作同步。
- 输出 MP4，码率以清晰展示文字为准。
