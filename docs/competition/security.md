# 安全与生产基线

## 身份认证

- 邮箱作为规范化唯一账号标识。
- 密码使用随机盐 `scrypt` 派生，禁止明文保存。
- 登录会话使用随机 opaque token；数据库只保存令牌哈希。
- Cookie 使用 `HttpOnly`、`SameSite=Lax`、`Path=/`；HTTPS 下启用 `Secure`。
- 注销会删除服务端会话记录。
- 登录和注册均有限流。

## 多租户授权

- 工作空间由登录会话推导，不接受客户端任意指定。
- 课程、资料、知识点、学习者、运行、资源和评估查询均包含工作空间条件。
- 跨工作空间对象统一返回 404，避免枚举和存在性泄露。
- 第一个注册用户接管迁移前的默认工作空间；后续账号自动获得独立工作空间。

## 上传安全

- 单文件上限 25 MB，Nginx 上限 30 MB。
- 工作空间默认上限 500 个资料和 500 MB 容量。
- 图片通过 Pillow 验证真实格式和像素预算。
- PDF 检查文件签名和页数上限。
- DOCX/PPTX 检查 Office ZIP 结构与解压后大小。
- 服务端使用规范 MIME 类型，不信任浏览器声明。
- 图片以内联方式用于预览，其他原始文件强制下载。
- 学习通文档导入单文件上限 100 MB；ZIP 上传 250 MB、解压总量 1 GB。
- 学习通 Cookie 使用 AES-256-GCM 加密，二维码 5 分钟失效，会话最多保留 24 小时。
- 学习通 URL 必须使用 HTTPS 且属于官方白名单；拒绝私网、IP、任意重定向和未知域名。
- ZIP 拒绝路径穿越、符号链接、加密成员、嵌套压缩包、超量和超大解压内容。
- ZIP 备用导入不依赖学习通在线会话；关闭在线连接器时仍可安全预览和导入。

## 网络与浏览器

- Nginx 配置 nosniff、SAMEORIGIN、严格 Referrer Policy、CSP 和 Permissions Policy。
- API、登录和注册分别限流。
- 写操作校验 Origin，Cookie 鉴权结合 `SameSite=Lax`。
- FastAPI 文档和健康检查不暴露密钥。

## 可观测性

- 每个响应返回 `X-Request-ID`。
- API 日志包含请求 ID、方法、路径、状态码、耗时、工作空间和用户 ID。
- `/api/health/live` 用于进程存活检查。
- `/api/health/ready` 检查数据库、上传目录和磁盘空间。
- 审计表记录认证和关键数据操作。

## 数据持久化

- SQLite 使用 WAL、`busy_timeout=5000`、`synchronous=NORMAL`。
- systemd 每日执行在线备份，进行 `PRAGMA integrity_check`，默认保留 14 天。
- 原始文件位于私有数据目录，不与来源代码或发布目录混放。

## 当前剩余风险

- 当前为单机 SQLite，不适合多节点横向扩展。
- 公网 HTTP 环境无法获得 `Secure` Cookie。
- 尚未实现邮箱验证、找回密码、密码修改、MFA、恶意文件扫描和 PostgreSQL 迁移。
- 登录限流当前为单进程内存实现，多 worker 时应迁移到 Redis。
- 后台生成任务仍依赖当前 API 进程，生产高可用版本应拆分独立 worker。
- 学习通没有面向本项目的公开 OAuth API；适配器依赖官方扫码页面和课程页面结构，上游改版时需要维护并可通过功能开关回退。
