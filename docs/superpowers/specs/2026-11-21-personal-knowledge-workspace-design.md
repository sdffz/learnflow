# 知序 LearnFlow 个人知识工作台设计规格

日期：2026-11-21  
状态：已确认，进入实施  
赛题依据：第十五届“中国软件杯”A3  
本阶段范围：用户自建知识文件夹、资料入库、本地知识提取、知识搜索、资料详情和个人知识首页

## 1. 产品目标

知序不再以固定的《人工智能导论》演示课程作为产品中心，而是先建立属于用户自己的个人知识库。用户可以把课程资料、课堂照片、网页摘录和手动笔记归入不同课程，系统从这些资料中提取可搜索的知识片段，再由画像、资源生成、路径、辅导和评估智能体基于个人知识库提供学习支持。

本阶段必须证明：

1. 用户可以建立、重命名和切换自己的知识文件夹。
2. 用户可以上传文件、拍照或直接写笔记，并明确归入某门课程。
3. 上传后的文件可以被解析为可搜索、可追溯的知识片段。
4. 用户能跨课程搜索自己的资料，并打开原始来源。
5. 知识管理流程不依赖演示学生和固定课程也能使用。
6. 既有五类赛题能力仍然保留，并在后续任务中改为引用个人资料。

```text

│   ├── 最近添加
│   ├── 待整理资料

│   ├── 薄弱知识点
│   └── 学习画像入口
├── 知识文件夹
│   ├── 课程列表
│   └── 课程详情
│       ├── 资料
│       ├── 笔记
│       ├── 知识点
│       └── 关联学习资源

│   ├── 知识卡片
│   ├── 标签筛选
```

## 3. 核心用户流程

### 3.1 首次使用

1. 系统显示知识首页和预置的“人工智能导论”示例课程。
2. 用户可以直接创建新课程，也可以进入示例课程。
3. 用户点击“添加知识”，选择课程并上传资料或拍照。
4. 资料保存后立即出现在知识文件夹和最近添加中。

### 3.2 添加资料

1. 用户选择采集方式：文件、拍照/图片、快速笔记。
2. 用户选择课程，填写可选标题和标签。
3. 文件进入私有存储；文本型资料提取正文，图片尝试本地 OCR。
4. 系统把正文拆分为知识片段，并生成摘要、标签和知识点候选。
5. 成功后显示资料卡片和提取片段数；失败时保留原始文件并提供失败原因和重试。

### 3.3 浏览与检索

1. 用户在知识库输入关键词。
2. 搜索覆盖课程名、资料标题、正文、标签和知识片段。
3. 结果展示命中片段、所属课程、资料名称和标签。
4. 用户打开知识片段或原始资料，查看可用的文字内容和文件预览。

### 3.4 进入学习智能体

1. 用户在课程详情中查看资料和知识点。
2. 用户完善学习画像后进入智能生成、路径、辅导和评估。
3. 后续智能体任务接收课程和资料范围，只基于用户选定的知识来源生成输出。

## 4. 第一版范围

### 4.1 包含

- 单用户私有工作空间。
- 知识文件夹创建、重命名、删除。
- 文件、图片和快速笔记入库。
- PDF、DOCX、PPTX、Markdown、TXT 文本提取。
- 图片在运行环境支持 Tesseract 时执行中英文 OCR；不支持时保留图片并明确提示只能进行图片归档。
- 资料标题、课程、类型、标签、正文摘要、处理状态和创建时间。
- 摘要生成、标签提取、知识片段切分和知识点候选。
- 课程详情资料列表和资料详情。
- 跨课程关键词搜索与标签筛选。
- 知识首页统计与最近资料。
- 桌面和手机响应式布局。
- 原始文件私有下载与图片预览。

### 4.2 不包含

- 账号注册、登录、邮箱验证和找回密码。
- 直接登录学习通或后台抓取未授权课程资料。
- 云对象存储迁移。
- 大视频上传和视频转写。
- 多人协作、公开知识库和教师端。
- 向量数据库；本阶段使用 SQLite 与中文文本匹配。
- 自动生成排版精美的知识图谱；先提供知识点列表、标签和课程访问链路。

## 5. 数据模型

所有数据属于安装实例的单一私有工作空间。模型预留 `workspace_id`，当前固定为 `default`，为后续认证和多人隔离保留迁移路径。

### 5.1 Course

```ts
interface Course {
  id: string;
  title: string;
  description: string;
  color: string;
  assetCount: number;
  knowledgeCount: number;
  updatedAt: string;
}
```

### 5.2 KnowledgeAsset

```ts
interface KnowledgeAsset {
  id: string;
  courseId: string;
  courseTitle: string;
  kind: "file" | "image" | "note";
  title: string;
  originalName: string | null;
  mimeType: string | null;
  status: "processing" | "ready" | "ready_image_only" | "failed";
  summary: string;
  content: string;
  tags: string[];
  knowledgeCount: number;
  error: string | null;
  createdAt: string;
  updatedAt: string;
}
```

### 5.3 KnowledgeChunk

```ts
interface KnowledgeChunk {
  id: string;
  assetId: string;
  assetTitle: string;
  courseId: string;
  courseTitle: string;
  title: string;
  excerpt: string;
  tags: string[];
}
```

### 5.4 KnowledgeOverview

```ts
interface KnowledgeOverview {
  courseCount: number;
  assetCount: number;
  knowledgeCount: number;
  pendingCount: number;
  recentAssets: KnowledgeAsset[];

}
```

## 6. 后端设计

### 6.1 模块边界

- `knowledge_domain.py`：课程、资料、知识片段和 API 请求模型。
- `ingestion.py`：文件类型校验、文本提取、OCR、摘要、标签、分块。
- `knowledge_store.py`：课程、资料、知识片段和搜索的 SQLite 持久化。
- `knowledge_api.py`：课程 CRUD、上传、列表、详情、搜索和概览 API。

### 6.2 存储

- 数据库继续使用现有 SQLite 文件。
- 原始文件保存到 `LEARNFLOW_DATA_DIR/uploads/`。
- 数据库只保存相对路径，不保存服务器绝对路径。
- 文件大小限制为 25 MB。
- 允许扩展名：`.pdf`、`.docx`、`.pptx`、`.md`、`.txt`、`.png`、`.jpg`、`.jpeg`、`.webp`。

### 6.3 API

- `GET /api/knowledge/overview`：首页统计、最近资料、课程和热门标签。
- `GET /api/courses`：课程列表。
- `POST /api/courses`：创建课程。
- `PATCH /api/courses/{course_id}`：编辑课程。
- `DELETE /api/courses/{course_id}`：删除课程、资料、片段和原始文件。
- `GET /api/courses/{course_id}/assets`：课程资料列表。
- `POST /api/courses/{course_id}/assets`：multipart 上传文件或图片。
- `POST /api/courses/{course_id}/notes`：创建快速笔记。
- `GET /api/assets/{asset_id}`：资料详情和知识片段。
- `GET /api/assets/{asset_id}/file`：读取原始文件。
- `DELETE /api/assets/{asset_id}`：删除资料、片段和原始文件。
- `GET /api/knowledge/search?q=&tag=`：跨课程搜索。

### 6.4 文本提取

- Markdown/TXT：按 UTF-8、GB18030 顺序解码。
- PDF：使用 `pypdf` 提取每页文字。
- DOCX：使用 `python-docx` 读取段落和表格。
- PPTX：使用 `python-pptx` 读取所有形状中的文字。
- 图片：使用 `pytesseract` 调用 `tesseract`，语言为 `chi_sim+eng`。
- OCR 或依赖不可用时：资料状态为 `ready_image_only`，错误字段说明原因，不删除原图。

### 6.5 知识提取

- 正文按约 700 字、最多 60 段切分。
- 摘要取正文前 180 字并压缩空白。
- 标签来源包括显式标签、Markdown 标题、重复出现的中英文术语和资料标题。
- 每个片段生成短标题和来源摘要，保留资料 ID 以便追溯。
- 不使用固定课程知识库替代用户资料。

## 7. 前端设计

### 7.1 页面

- `KnowledgeDashboardPage`：知识首页、课程概览和最近资料。
- `CoursesPage`：知识文件夹列表、创建与重命名。
- `CourseDetailPage`：文件夹资料、知识点和上传入口。
- `KnowledgePage`：全局搜索、标签筛选和知识卡片。
- `AssetDetailPage`：资料详情、正文、标签、知识片段和原始文件。
- `CaptureDialog`：全局采集面板，支持文件、拍照/相册、快速笔记。

### 7.2 状态与反馈

- 上传时显示具体文件、处理进度文案和禁用重复提交。
- 成功显示“已入库，提取 N 个知识片段”。
- OCR 不可用时显示“图片已保存，但当前环境未启用文字识别”。
- 失败显示原因，并保留用户已选课程、标题和标签。
- 删除课程和资料前必须确认。
- 搜索无结果时展示可操作提示，而不是空白。

### 7.3 响应式

- 桌面端保留侧边栏，内容区使用课程卡与资料卡。
- 手机端使用固定底部导航。
- 课程列表在手机端单列；知识统计横向滚动。
- 采集面板在手机端从底部弹出。

## 8. 既有能力整合

- 当前《人工智能导论》知识库作为示例课程的初始资料导入，不再作为用户唯一知识来源。
- 学习画像、资源生成、学习路径、辅导和评估页面保留。
- 本阶段首先让课程、资料和知识点成为全局可访问的数据层。
- 下一阶段将资源生成请求扩展为 `{ courseId, topic, sourceAssetIds }`，智能体从用户资料提取上下文并返回引用。

## 9. 安全与隐私

- 上传内容只保存在私有部署的数据目录，不进入 Git 或日志。
- 文件名只用于展示；服务器文件名使用 UUID。
- 原始文件路径通过数据库 ID 解析，拒绝目录穿越。
- HTML/Markdown 资料不作为可执行页面渲染。
- 学习通不做账号代登录和后台抓取；用户通过自己导出的文件或主动上传资料进入个人知识库。
- 删除资料时只删除数据库中已验证属于该资料的相对路径。

## 11. 验收标准

- 首次打开先看到个人知识工作台，而不是演示学生选择页。
- 用户可以不建立画像就先管理课程和资料。
- 至少支持一种文件、一种图片和快速笔记入库。
- 文本资料入库后能在课程详情和全局搜索中找到。
- 搜索结果能追溯回具体课程和资料。
- 课程和资料删除均有确认和可见结果。
- 手机端“添加知识”入口可完成拍照或文件选择。
- 后端现有测试、新增知识库测试、前端测试、生产构建和浏览器主流程全部通过。
- 公网部署后完成一次真实上传、搜索和详情查看验收。
